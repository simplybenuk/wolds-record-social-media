# Handoff Contract

Every workflow handoff includes:

- objective and scope
- confirmed decisions and assumptions
- relevant files or artifact paths
- acceptance criteria
- stop conditions
- validation requirements

Every workflow result includes:

- work completed or findings
- decisions and assumptions
- unresolved questions or blockers
- files inspected or changed
- validation evidence
- recommended next handoff

Persist detailed traceability in the repository's spec, planning, progress, or review artifacts. Keep the chat handoff proportional: lead with the outcome, link the authoritative artifact, include only material decisions, blockers, validation, and the next action, and do not repeat full artifact contents or exhaustive file and context lists.

Apply the autonomy, collaboration, completion, model-routing, and state
contracts from this directory where relevant. Project adapters add local
validation and source-of-truth requirements.
