# Agent Notes

This repository is a lightweight social media automation workspace for Wolds Record.

Agents working in this repo should append a brief dated entry to `agents_log.txt` after making meaningful changes. Include:

- local timestamp
- short summary of files changed
- any important verification run
- any manual follow-up needed

Keep entries concise and factual. Do not store secrets, API keys, or private credentials in the log.
